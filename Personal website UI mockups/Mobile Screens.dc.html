What changed to get here

Display sizes are now fluid — the home headline runs 68px down to 35px, prose 20px down to 17px — so the measure stays readable without a second type scale. Sidebar rails (news, TOC, About card, publications glance) are flex columns that drop below the content; on the masthead home layout the rail deliberately wraps above the index so the name still leads. Post list rows wrap their date onto a second line rather than crushing the title, and the card view collapses from three columns to one. Page padding tightens from 32px to 18px.

Still worth a decision: justified prose holds up to about 34 characters a line, which is where a phone lands. In Quarto I would set body copy ragged-right below roughly 600px and keep justification for the desktop measure.
